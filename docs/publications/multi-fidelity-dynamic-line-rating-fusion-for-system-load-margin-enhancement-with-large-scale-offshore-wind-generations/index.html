Multi-Fidelity Dynamic Line Rating Fusion for System Load Margin Enhancement with Large-Scale Offshore Wind Generations

Tong Su, Junbo Zhao, Emil M. Constantinescu, Cosmin G. Petra

IEEE Transactions on Power Systems 41 (5), 3979–3992

Author manuscript (PDF)DOIResearchGateBibTeX

Research summary

This work combines multi-fidelity dynamic line rating with uncertainty calibration and learned load-margin models. It connects fast surrogate predictions to operational security quantities for systems with large-scale offshore wind generation. The study focuses on using transmission infrastructure more effectively while maintaining attention to uncertainty and system load margin.
